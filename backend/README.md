# Backend — Controle de Vendas

API REST em Spring Boot.

## Próximo passo

Gerar o projeto via [Spring Initializr](https://start.spring.io) com as dependências:

- Spring Web
- Spring Data JPA
- Driver do banco escolhido (PostgreSQL/MySQL)
- Validation
- Spring Boot DevTools (opcional, dev)
- Lombok (opcional)

Extrair o conteúdo gerado dentro desta pasta `backend/`.

## Estrutura sugerida de pacotes

```
com.suaempresa.controlevendas
├── config/
├── controller/
├── service/
├── repository/
├── model/ (entities)
├── dto/
└── exception/
```
